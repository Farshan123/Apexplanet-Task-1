# ApexPlanet Data Analytics Internship – Task 1

## Data Immersion & Wrangling

### 📌 Project Overview
This project is part of the ApexPlanet Data Analytics Internship. It focuses on exploring, assessing, cleaning, and transforming raw datasets into a structured, analysis-ready format using Python.

### 🎯 Objectives
- Understand the dataset structure and column details.
- Identify missing values and duplicate records.
- Detect inconsistent formats and potential outliers.
- Clean and transform data appropriately.
- Create a data dictionary.
- Validate and export the cleaned dataset.

### 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Visual Studio Code
- Git and GitHub

### ⚙️ Installation and Setup

**1. Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**
```bash
cd ApexPlanet-Task-1
```

**3. Install dependencies**
```bash
python -m pip install -r requirements.txt
```

**4. Place the dataset**

Place your original CSV file inside the `data/` folder and name it `raw_dataset.csv`.

**5. Run the Python script**
```bash
python task1_cleaning.py
```

### 🔍 Project Workflow
1. Load and explore the dataset.
2. Analyze columns, data types, and summary statistics.
3. Assess missing values and duplicate records.
4. Document column information in the data dictionary.
5. Perform appropriate data cleaning and transformations.
6. Validate the cleaned dataset.
7. Export the cleaned data and quality reports.
